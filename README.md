# Memory Game 🧠

An interactive memory-matching game built with HTML, CSS, and JavaScript.

## Overview

Memory Game is a card-matching game designed to test and challenge the player's memory.

At the beginning of the game, all cards are displayed so the player can memorize their positions. The cards are then flipped over, and the player must find and match pairs of identical cards using their memory.

The goal is to match all identical pairs.

## Features

- **Memory Challenge:** Test your ability to remember card positions.
- **Initial Card Preview:** View all cards before they are flipped.
- **Card Matching:** Find and match pairs of identical cards.
- **Interactive Gameplay:** Flip cards and discover whether they match.
- **Memory Training:** Practice concentration and visual memory.
